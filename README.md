# 链智采购

- **项目全称：** 链智采购——基于 HarmonyOS 的智能采购对账与风险辅助系统
- **团队名称：** 链智先锋队
- **项目简称：** 链智采购
- **工程名称：** ChainWiseProcure

## 项目介绍

“链智采购——基于 HarmonyOS 的智能采购对账与风险辅助系统”由链智先锋队开发。系统面向采购对账业务，通过导入采购订单、发票、收货及付款数据，自动识别单据缺失、数量差异、价格异常和付款异常，形成对账结果与风险提示，并辅助采购人员完成差异核查和风险处置。

## 核心功能

### 采购数据导入

- 选择 CSV 文件或粘贴 CSV 文本；
- 校验采购订单、供应商、发票、收货和付款字段；
- 显示具体的格式错误、字段错误和对应行号。

### 自动对账

- 按任务编号关联采购订单、发票、收货记录和付款记录；
- 检查发票、收货记录及付款记录是否缺失；
- 检查采购数量、发票数量和收货数量是否一致；
- 检查采购单价、发票单价、订单金额和付款金额是否一致；
- 将任务划分为“已完成”“存在差异”或“待补充材料”。

### 差异处理

- 查看对账任务列表与差异详情；
- 确认对账差异；
- 生成处理建议；
- 标记任务为已处理。

### 风险辅助

- 按风险等级展示采购异常；
- 查看风险涉及的供应商、金额及业务证据；
- 提供核查步骤和处置建议；
- 支持确认风险、创建核查任务和采纳建议等演示流程。

### 链智 AI 助手

- 分析高风险供应商；
- 解释对账差异；
- 提供采购异常处理建议。

## 业务流程

1. 导入采购订单、发票、收货和付款数据；
2. 校验 CSV 数据格式及必填字段；
3. 执行采购单据自动匹配与差异检查；
4. 查看对账结果和风险提示；
5. 确认差异、生成处理建议并记录处理状态。

## 当前能力边界

- 对账引擎和 CSV 校验为本地真实运行的规则程序；
- 风险中心当前主要使用内置演示数据；
- 链智 AI 助手目前使用预设规则和固定回复，尚未接入 GPT 或其他大模型 API；
- 当前尚未接入企业 ERP、电子发票平台、供应商系统或真实付款系统；
- CSV 批次主要在本次应用运行期间使用，持久化服务尚未完全接入页面流程；
- 当前版本定位为可运行的 HarmonyOS 采购对账与风险辅助原型系统。
